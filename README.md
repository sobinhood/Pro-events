# Pro events

Event Scout — личный агент, который раз в неделю ищет деловые мероприятия: банки и private banking, wealth management, инвестиции, финтех, хай-тек. Результат — строки в таблице Google Sheets, предварительные события в Google Calendar и дайджест письмом.

## Как это устроено

Агент — это запланированная задача Claude Code «Event Scout». Кода здесь нет: всё поведение задаётся инструкцией в [`AGENT.md`](AGENT.md). Каждый запуск стартует новую сессию, которая выполняет эту инструкцию.

| | |
| --- | --- |
| Расписание | каждый понедельник, 04:49 UTC |
| Источники | письма-приглашения от LinkedIn, Luma, Eventbrite, Meetup; обход по городам через веб-поиск и календари организаторов |
| Города | полный обход: Израиль, Кипр, Дубай и Абу-Даби, Лондон; конференции: Швейцария, Люксембург, Монако, Залив |
| Результат | таблица с ценой и условием входа (бесплатно, платно, по приглашению), календарь (события с оценкой 4–5), письмо на русском владельцу и дополнительным получателям |

Задаче нужны три коннектора: Gmail, Google Sheets и Google Calendar. Без них поиск проходит, но результаты никуда не записываются.

## Как менять агента

Рабочая копия инструкции хранится в самой задаче, этот файл — её история. Порядок такой:

1. Поправить `AGENT.md`.
2. Вставить текст в инструкцию задачи «Event Scout», заменив заглушки `<SPREADSHEET_ID>`, `<OWNER_EMAIL>` и `<EXTRA_RECIPIENTS>` на настоящие значения.

Заглушки стоят намеренно: репозиторий публичный, адреса почты и ID таблицы в него не кладём.

## Ограничения

- Агент не входит ни в какие аккаунты. Из LinkedIn он видит только публичные страницы и то, что LinkedIn присылает на почту.
- Даты событий агент сверяет на сайте организатора. Если подтвердить не удалось, строка получает статус «проверить дату».
